B站AI视频分析助手 是一个面向 Bilibili 学习视频场景的 AI 扩展。

主要功能：
1. 对当前学习内容生成时间轴摘要
2. 支持继续对话
3. 支持图片分析
4. 支持生成思维导图
5. 支持安装自定义 Skill
6. 支持历史会话搜索与恢复
7. 支持中英文界面切换

测试方式：
1. 打开任意 https://www.bilibili.com/video/* 页面
2. 打开扩展
3. 在 API 配置 页面填写可用的模型接口信息
4. 点击 应用
5. 回到主界面测试 摘要、图片分析、继续对话
6. 在 思维导图 页面测试导图生成和图片导出
7. 在 Skill 安装 页面测试上传或粘贴 Skill 文件
8. 在 对话输入区测试 历史会话 按钮，搜索并恢复之前的会话

重要说明：
1. 本扩展采用“用户自带 API Key”模式
2. 审核人员需要填写可用的 AI 服务商接口信息后，摘要、对话、图片分析、思维导图等功能才能返回正常结果
3. 当前支持的预置供应商包括 DeepSeek、Qwen、GLM、MiniMax、MiMo、Kimi，也支持自定义 OpenAI 兼容接口
4. 图片分析能力依赖所配置模型是否支持视觉输入
5. 扩展主要面向 Bilibili 视频学习场景设计
