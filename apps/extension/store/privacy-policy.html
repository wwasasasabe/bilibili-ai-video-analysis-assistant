B站AI视频分析助手 隐私政策

本隐私政策说明 B站AI视频分析助手 如何处理扩展运行过程中涉及的数据。用户安装并使用本扩展，即表示理解本政策中描述的数据处理方式。

1. 数据处理范围

本扩展仅在用户主动使用功能时处理与当前任务相关的数据，例如当前视频标题、用户输入的问题、用户主动上传的图片、Word 文档、代码文件，以及用户主动触发的摘要、对话、图片分析、思维导图请求。

2. API Key 与本地配置

用户填写的 API Key、模型配置、语言偏好、提示词配置、历史会话和 Skill 配置默认保存在用户本地浏览器存储中，用于提供连续体验。本扩展不会默认将这些本地配置发送到与当前功能无关的第三方。

3. 第三方 AI 服务

当用户主动发起摘要、对话、图片分析或思维导图请求时，相关输入内容会发送到用户所配置的 AI 服务提供商接口。用户应自行了解并遵守所选 AI 服务提供商的隐私政策与使用条款。

4. 历史会话

历史会话功能用于帮助用户搜索和恢复之前的对话内容。历史会话默认保存在本地浏览器存储中，不会被自动公开或共享。

5. 用户上传附件

用户上传的图片、Word 文档、代码文件仅用于当前用户主动发起的分析任务。扩展不会在未触发相关功能的情况下自动处理这些附件。

6. 数据共享与出售

本扩展不会默认出售用户个人数据，也不会在与扩展核心功能无关的情况下共享用户数据。

7. 数据删除

用户可以通过清除浏览器扩展存储、删除历史会话或卸载扩展来移除本地保存的数据。

8. 联系方式

如需更新本页面中的联系方式或运营信息，请在发布前替换为你的实际邮箱、网站或支持页面地址。
